# Quick Start — LibreGameDev for Grok Build

> From zero to a game-feel review in under 5 minutes.

## Prerequisites

- Grok Build installed and working
- A game project (Godot / Unity / Unreal / web) you own

## Install skills (repo-local)

```bash
git clone https://github.com/HermeticOrmus/LibreGameDev-Grok-Build.git
cd your-project
mkdir -p .grok/skills
cp -R /path/to/LibreGameDev-Grok-Build/skills/* .grok/skills/
```

Or user-global:

```bash
mkdir -p ~/.grok/skills
cp -R /path/to/LibreGameDev-Grok-Build/skills/* ~/.grok/skills/
```

## First-run teach cue

1. **Feel** — "Run game-loop-feel on player movement and feedback."
2. **Input** — "Run input-feel for buffering, deadzones, and cancel windows."
3. **Playtest** — "Run playtest-checklist for a 15-minute session plan."
