# Game Loop Feel

Game feel: timing, juice, feedback loops that make controls sing.

## Steps
1. Name the verb (jump, shoot, dash).
2. Measure response latency targets.
3. Add juice without noise.
4. Fail states that teach.
5. Ship a feel checklist.
