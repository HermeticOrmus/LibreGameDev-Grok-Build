1. Install the `libre-gamedev-grok` plugin, plus the pack plugins you need, from this repo's marketplace (see [QUICK_START.md](./QUICK_START.md)).

3. Use suite skills for GameDev; use `AGENTS/gamedev-orchestrator.md` when a full multi-skill pass is needed.
